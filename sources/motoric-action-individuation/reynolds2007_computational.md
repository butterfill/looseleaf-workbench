# \citet{reynolds:2007_computational}: prediction-error segmentation in a learned environment

**Model.** Networks were trained to predict the next state of continuous sequential input based on movement trajectories. A maintained context representation is useful *within* an event; increased prediction error can signal when to update this state at an event boundary. Several simulations compared event-unit prediction and methods for opening the contextual gate, culminating in an approach that learns a useful prediction-error signal without direct supervised instruction for every boundary.

**Result and significance.** The paper demonstrates a **computational possibility**: recurring temporal regularities can train a system to form event-sensitive representations that improve online prediction and identify many transitions using prediction error. In its fourth simulation a self-organizing network achieved about 82.9% identification of experimenter-designated boundaries and around 10.5% false alarms (see Simulation IV results and general discussion). This is substantial as an alternative mechanism for perceptual segmentation, not generic acknowledgement of “prediction.”

**Important limitation.** The simulation environment was built by **concatenating predefined event sequences**; their boundaries were supplied by the experimenter's construction of the training environment, not discovered as philosophically privileged action individuals by an embodied learner. A model tracking statistical contingencies need not simulate performing the actions, nor determine which pieces deserve recognition as individual *actions in thought*. Conversely its success does not disprove that motor representations help form specific units in real observers. Performance against preset event boundaries is not a test of action ontology.

**Theoretical bearing.** One can distinguish a *motor-specific* action-index hypothesis from a more general **predictive event-model** account. The latter supplies a concrete rival rather than a background strawman. A discriminating study must explain what a motor representation adds beyond trained expectations and surprise-driven boundary updating.
