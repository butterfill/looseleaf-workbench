# \citet{zacks:2001_perceiving}: hierarchical events and null expertise findings

Zacks, Jeffrey M., Barbara Tversky & Gowri Iyer (2001), “Perceiving, remembering, and communicating structure in events.” Verified Personal Papers key: \`zacks:2001_perceiving\`.

**Access:** Original Personal Papers full text. Read abstract, event segmentation and description methods/results, Experiments 2–3 and their discussion, plus portions of the memory experiment.

**Findings.** When observers segmented ordinary activity into coarse and fine events, boundaries aligned in ways consistent with hierarchical partonomies. Descriptions of the identified parts likewise manifested hierarchy. That connects perceptual boundaries with some of the units used in *thinking and talking* about activity.

**Counterfinding that must be preserved.** The predicted training/expertise differences were not established in Experiments 2–3. One Experiment 2 analysis was even contrary to prediction; another was null, and comparisons did not reveal clearly different segmentation-location distributions. The paper should not be summarized as showing that acquiring a skill reorganizes perceived action units.

**Limit.** These are mainly event segmentation and description measures, not causal manipulations of *motor* representation or definitive judgments about action identity. Conceptual event schemata, familiarity and physical features could explain the structure.
