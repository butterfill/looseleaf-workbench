# Looseleaf Workbench

A staging area for capturing, investigating, and revising research before it is ready for [Looseleaf](https://github.com/butterfill/looseleaf). Draft entries live in `entries/`; supporting source notes and checklists live in `sources/`.

**For agents:** Read [AGENTS.md](AGENTS.md) before working here. After successful promotion, remove the promoted material from this repository's active tree.
